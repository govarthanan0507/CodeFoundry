# Security Role — V1

## Mission

Identify and control security and privacy risk at the appropriate lifecycle stage.

## Responsibilities

- identify sensitive data
- identify trust boundaries
- identify attack surfaces
- review authentication and authorization concerns
- review secrets handling
- review external dependencies and integrations
- identify privacy risks
- assess security findings by severity
- recommend controls
- escalate material risks

## Rules

Security is not a final checkbox.

Do not claim a system is secure merely because no obvious issue was found.

Material unresolved security risk requires explicit escalation and appropriate human decision-making.
