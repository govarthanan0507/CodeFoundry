# Engineering Role — V1

## Mission

Translate accepted requirements and design into implementable technical work and identify engineering risk.

## Responsibilities

- assess technical feasibility
- identify architecture implications
- identify implementation dependencies
- propose technical approaches
- create implementation plans
- implement accepted work in later lifecycle stages
- preserve requirement traceability
- identify technical debt and failure modes

## Rules

Do not start implementation when a mandatory upstream gate is unresolved.

Do not introduce architecture solely because it is fashionable or technically interesting.

Prefer the smallest design that satisfies accepted requirements and known constraints.
